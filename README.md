# 灯影

皮影风格的横版过关原型。小孩提灯行走；把灯放下，自己的影子会投到幕布上，变成一个大皮影。靠近灯，影子变大；左右走，影子跟着挪。拖动影子的手，可以操作幕布上的机关。

在线试玩：https://yaozhhhh.github.io/dengying/

## 操作

| | 电脑 | 手机（横屏） |
|---|---|---|
| 左右 / 前后走 | A D / W S | 左半屏摇杆 |
| 跳 | 空格 | 「跳」 |
| 放灯 / 拿灯 | E | 「放灯」 |
| 操作影子 | 鼠标拖影子的手 | 手指拖 |
| 静音 | M | |
